# Arabic Math Exam — Sample Extractions

Sample input pages alongside their structured extractions. Each page links
to a Markdown preview of the extracted questions, options, and correct
answers. Cropped diagrams from each page are included alongside the
structured data.

## Combined deliverables

- [deliverables/questions.json](deliverables/questions.json) — structured data for every page
- [deliverables/questions.csv](deliverables/questions.csv) — flat one-row-per-question CSV
- [deliverables/images/](deliverables/images/) — every cropped diagram, named <page>_question_<N>_diagram.png
- [deliverables/summary.md](deliverables/summary.md) — combined Markdown preview of all pages
