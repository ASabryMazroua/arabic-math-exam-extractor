# Arabic Math Exam - Sample Extractions

Sample input pages alongside their structured question extractions. Each page links
to a Markdown preview of the extracted question items, options when visible,
correct answers where available, and cropped diagrams where present.

## Combined Deliverables

- [`deliverables/questions.json`](deliverables/questions.json) - structured data for every page
- [`deliverables/questions.csv`](deliverables/questions.csv) - flat one-row-per-question CSV
- [`deliverables/images/`](deliverables/images/) - cropped diagrams extracted from the pages
- [`deliverables/summary.md`](deliverables/summary.md) - combined Markdown preview of all pages
